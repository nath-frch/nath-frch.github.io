SAÉ2.03 - Mettre en place une solution informatique

  • Accueil

Le projet :

Création d'une application Django et gestion d'une base de données via cette dernière.

Durant cette SAÉ, nous avons créé en groupe une base de données composée de plusieurs tables liées entre elles, qui devaient communiquer. Le projet comprenait aussi une partie reverse proxy (Nginx) et Django pour l'affichage web. Dans Django, nous avons également développé les différents CRUD pour envoyer les données dans la base, en faisant attention aux différentes relations entre les tables.

Apprentissages critiques :

  • AC13.02 | Lire, exécuter, corriger et modifier un programme
  • AC13.04 | Connaître l'architecture et les technologies d'un site Web
  • AC13.05 | Choisir les mécanismes de gestion de données adaptés au développement de l'outil et argumenter ses choix
  • AC13.06 | S'intégrer dans un environnement propice au développement et au travail collaboratif
